# Reference

Look-up pages for when you know the idea and need the exact word, command or number. The lessons teach; these pages are for finding things fast. Each entry links back to the lesson that explains it.

- [Glossary](glossary.md): the terms the lessons define, in alphabetical order.
- [Command cheat sheets](commands.md): Linux shell, Git, Docker and Compose, psql, npm and pip, curl, kubectl and the AWS CLI.
- [Ports, status codes and latency numbers](ports-status-codes-and-latency.md): the values worth remembering.
- [Common mistakes](common-mistakes.md): the warnings from every lesson, grouped by section.

The glossary and the common mistakes pages are generated from the lessons. The command and number tables are written by hand.
