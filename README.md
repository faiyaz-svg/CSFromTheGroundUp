# CS From the Ground Up

A self-study textbook on computer science and software development, from how computers work to Linux, Python, data structures, SQL and Postgres, the web, security, cloud and working with AI tools. Lessons are short, each with a quiz and a hands-on lab.

Read it online: https://faiyaz-svg.github.io/CSFromTheGroundUp/

The sibling book on maths: [Math From the Ground Up](https://faiyaz-svg.github.io/MathFromTheGroundUp/).

## Preview locally

```bash
py -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/zensical serve
```

Then open http://127.0.0.1:8000/CSFromTheGroundUp/. The writing rules are in `STYLE.md`, the lesson layout in `LESSON_TEMPLATE.md` and the site design in `DESIGN.md`.
